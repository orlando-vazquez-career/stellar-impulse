# Recursos visuales del README

Preparados el 9 de octubre de 2026 para documentar el prototipo de Stellar Impulse.

| Archivo | Procedencia y alcance |
|---|---|
| `stellar-impulse-banner.svg` | Banner vectorial con el símbolo y la paleta del proyecto; texto seleccionable en el SVG |
| `command-center.png` | Captura real del centro de mando con alias de invitado «Vega» |
| `hangar.png` | Captura real del hangar como invitado, sin wallet vinculada ni firma |
| `gameplay.png` | Captura real de práctica en Espiral con cliente conectado a una sala de entrenamiento local |
| `business-scenarios.svg` | Gráfica vectorial de los escenarios hipotéticos del README; escala lineal, venta primaria y comisión secundaria separadas |

Las capturas usan Chromium headless y viewport de 1600 × 1000. No se alteró la interfaz para simular propiedad, resultados ni actividad económica. No acreditan la validación manual de Freighter ni un despliegue público.

La gráfica usa 120 + 10 = 130, 800 + 75 = 875 y 4.000 + 400 = 4.400 XLM. Estos valores explican el modelo propuesto; no representan ingresos ni usuarios reales. Los mismos supuestos y datos aparecen como tabla y fórmula en el README.

Los diagramas de gameplay, recorrido del jugador, arquitectura, compraventa y roadmap se mantienen como Mermaid en el README, para conservar su texto y facilitar revisión y edición.
